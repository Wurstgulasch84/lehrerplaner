# Lehrerplaner Sachsen 2026/27

Persönlicher Lehrerplaner als Web-App: läuft auf PC, Tablet und Handy, auch ohne Internet.
Adresse: https://wurstgulasch84.github.io/lehrerplaner/

- Daten liegen auf dem jeweiligen Gerät, der Abgleich zwischen Geräten läuft Ende-zu-Ende verschlüsselt über Dropbox.
- In diesem Repository liegt nur der Programmcode, keine Schülerdaten.
- Quelle: `quelle/app.html`; `python3 quelle/build.py` baut daraus die ausgelieferten Dateien.
